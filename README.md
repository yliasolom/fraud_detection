# Домашнее задание: Обучение модели для задачи Fraud Detection с использованием PySpark и MLflow

## Задание
1. Обучить модель для задачи fraud detection.
2. Настроить MLflow для хранения артефактов модели (использовать Object Storage в качестве backend).
3. Сохранить артефакты модели в MLflow.
4. Настроить регулярное переобучение модели на новых данных с использованием Apache Airflow.

## Описание решения

### 1. Обучение модели с PySpark
- Процесс обучения включал :
  - Очистка данных и преобразование признаков.
  - Добавление временных признаков (месяц, день недели, время суток).
  - Подготовка данных с использованием **VectorAssembler** и **StandardScaler** для масштабирования признаков.
  
### 2. Настройка MLflow для хранения артефактов модели
- **MLflow** использован для хранения и управления артефактами модели.
- Настроен **Object Storage** как backend для хранения артефактов, таких как:
  - Модель.
  - Параметры.
  
### 3. Сохранение артефактов в MLflow
- После можель с лучшими параметрами была зарегистирована с `mlflow.spark.log_model` как `best-fraud-detection`
 
### 4. Регулярное переобучение модели с использованием Airflow
- Настроен **Airflow** для регулярного переобучения модели.
- DAG выполняет:
  - Обработку данных.
  - Обучение модели.
  - Сохранение модели и метрик в **MLflow**.

## Результаты
- Модель успешно обучена и сохранена в **MLflow**.
- Регулярное переобучение настроено через **Apache Airflow** для обновления модели с новыми данными.
