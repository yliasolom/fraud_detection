# OTUS. Практика. Конвейер подготовки данных


В рамках данного задания настроен и реализован конвейер подготовки данных с использованием:
- **Yandex.Cloud** для развертывания инфраструктуры.
- **Terraform** для конфигурации и автоматизации инфраструктуры.
- **Airflow** для оркестрации процесса обработки данных.
- **Spark** для обработки данных в распределенной среде.
- **Dataproc** для работы с данными в Yandex Cloud.
